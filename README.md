# 🐳 Dockerized Full-Stack App with Playwright Testing

A containerized full-stack application designed to demonstrate modern **DevOps and QA Automation practices**, including multi-service orchestration with Docker, automated UI testing with Playwright, and continuous integration using GitHub Actions.

---

## 🏷️ Tags

`docker` `docker-compose` `playwright` `qa-automation` `ci-cd` `github-actions` `testing` `devops` `containerization` `automation-testing`

---

## 📌 Project Overview

This project was created as part of my **QA Automation portfolio** to showcase practical experience with **containerized environments, automated testing, and CI/CD pipelines**.

The application is structured as a **multi-container architecture** that includes a frontend, backend, and database, all orchestrated with Docker Compose.

In addition, a basic **UI testing suite using Playwright** is integrated into the development workflow and automatically executed through **GitHub Actions** on every push to the repository.

Test results are published and can be reviewed through **GitHub Pages**, providing a transparent view of the test outcomes for each deployment.

## 🏗️ Architecture

The application runs using a **multi-container Docker environment**, where each service is isolated and managed independently.

### Services included

- **Frontend** – User interface of the application  
- **Backend** – API and application logic  
- **Database** – Persistent data storage  
- **Testing Suite** – UI tests executed with Playwright  

Docker Compose orchestrates the startup process, building and running each service using its corresponding Dockerfile.

---

## 🧪 Automated Testing

This project includes a **basic UI automation test suite built with Playwright** that validates key user interactions in the application.

### Key features

- End-to-end UI tests  
- Automated execution on every repository push  
- CI integration with GitHub Actions  
- Generated HTML reports for test results  

---

## 🔄 Continuous Integration

A **GitHub Actions workflow** is configured to automatically run the Playwright test suite on every push.

### CI Pipeline steps

1. Installing project dependencies  
2. Setting up the testing environment  
3. Running Playwright UI tests  
4. Generating test reports  
5. Publishing the reports to GitHub Pages  

This allows anyone reviewing the project to easily inspect the **test execution results for each deployment**.

---

## 📊 Test Reports

Test results are automatically published via **GitHub Pages**, allowing easy access to the execution reports generated by Playwright.

These reports include:

- Test execution status  
- Detailed error traces  
- Screenshots for failed tests  
- Execution timing information
